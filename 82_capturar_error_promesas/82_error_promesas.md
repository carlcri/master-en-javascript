# 82 capturar Error

Usando la sentencia catch. 
```js
     .catch(error=>{
          console.log(`ERROR: ${error}`);
     });
```

Por ejemplo, prueba desconectar el internet, y mira el error que aparece en consola. Tambien puedes agregar una alerta
